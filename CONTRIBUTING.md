# Contributing to EagleEye

We are excited that you are interested in contributing to the EagleEye Surveillance System! This project aims to improve security in Nigerian Local Governments through collaborative open-source innovation.

## How to Contribute

### 1. Reporting Bugs
- Use the GitHub Issue tracker to report bugs.
- Include details about the hardware version (High-End or Budget) and software environment.

### 2. Suggesting Enhancements
- If you have an idea for a more cost-effective sensor or a better communication protocol, open an issue to discuss it.

### 3. Pull Requests
- Fork the repository.
- Create a new branch for your feature or fix.
- Ensure your documentation is clear and follows the existing Markdown style.
- Submit a PR with a detailed description of the changes.

## Coding Standards
- **Documentation:** All documentation should be in English, clear, and professional.
- **Python Code:** Follow PEP 8 standards. Use type hinting where possible.
- **Hardware Docs:** Provide clear costs (in USD and NGN) and local sourcing suggestions for Nigeria.

## Community Guidelines
- Be respectful and professional.
- Focus on technical excellence and practical scalability for the Nigerian context.

Thank you for helping us make Nigeria safer!
