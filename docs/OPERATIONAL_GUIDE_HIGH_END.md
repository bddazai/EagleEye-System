# Operational Guide & Training: Eagle Eye Surveillance Initiative

This guide outlines the deployment, operational protocols, and training curriculum for the Eagle Eye system.

## 1. Deployment Workflow

### Phase A: Site Selection (Pre-Deployment)
1. **Identify High-Risk Zones:** Map recent kidnapping/banditry hotspots using local intel.
2. **Launch Point (LZ) Setup:** Select a secure LGA building or fortified outpost with a clear 360-degree view.
3. **Comms Check:** Deploy Starlink dish and verify >50Mbps download / >10Mbps upload.
4. **Mesh Link:** Verify Silvus Mesh connection between the drone base and at least two mobile ground units (Patrol Vehicles).

### Phase B: Operational Routine (Daily)
1. **Dawn/Dusk Patrols:** Execute automated flight paths during "high-threat" transition hours.
2. **Forest Penetration:** Use H20T Thermal sensor to scan forest edges for heat signatures of campsites or hidden vehicles.
3. **Alert Validation:** When a potential threat is spotted, use 23x Zoom to confirm, then drop a GPS pin in FlightHub 2.
4. **Community Notification:** Push coordinates and a snapshot to the Community Security Alert Group.

## 2. Training Curriculum (2-Week Intensive)

### Week 1: Technical Foundations
- **Day 1-2:** UAV Physics and M350 RTK Hardware Overview.
- **Day 3:** Battery Management & Solar Charging Safety.
- **Day 4:** Sensor Mastery (Switching between Zoom, Thermal, and Laser Rangefinder).
- **Day 5:** Software Setup (FlightHub 2, Mission Planning, 2D/3D Mapping).

### Week 2: Tactical Operations
- **Day 6-7:** Flight Maneuvers in High Wind and Low Visibility.
- **Day 8:** Emergency Procedures (Signal Loss, GPS Jamming, Manual Landing).
- **Day 9:** Tactical Communication (Radio protocols + Mesh data sharing).
- **Day 10:** Integration Drill (Simulated bandit sighting and coordination with Vigilante groups).

## 4. Safety & Security Rules
- **Rule 1:** NEVER fly above 120m AGL without NCAA clearance.
- **Rule 2:** Secure all ground equipment in "SafeHaven" armored cases when not in use.
- **Rule 3:** All data stored on local servers must be AES-256 encrypted.
- **Rule 4:** Operator must maintain LOS (Line of Sight) unless using BVLOS approved protocols.
